\chapter{Contributing}\label{contributing}}

You are welcome to help improve these AI learning notes through issues or pull requests.

The author is currently a student and may not be able to review or merge pull requests promptly. Thank you for your understanding if your contribution is not handled immediately.

\Needspace{5\baselineskip}
\hypertarget{suggested-types-of-feedback}{%
\section{Suggested Types of Feedback}\label{suggested-types-of-feedback}}

\begin{itemize}
\tightlist
\item
  Conceptual errors
\item
  Formula errors
\item
  Errors or omissions in reconstructed image content
\item
  Missing references
\item
  Outdated information
\item
  Potential copyright concerns
\item
  Learning path suggestions
\item
  Typesetting and link problems
\end{itemize}

\Needspace{5\baselineskip}
\hypertarget{suggested-information-to-include-in-an-issue}{%
\section{Suggested Information to Include in an Issue}\label{suggested-information-to-include-in-an-issue}}

\begin{itemize}
\tightlist
\item
  Path to the document containing the error
\item
  Excerpt from the original text
\item
  Description of the problem
\item
  Suggested correction
\item
  Links to reference sources or paper details
\end{itemize}

\Needspace{5\baselineskip}
\hypertarget{guidelines-for-pull-requests}{%
\section{Guidelines for Pull Requests}\label{guidelines-for-pull-requests}}

\begin{itemize}
\tightlist
\item
  Keep Chinese wording accurate, clear, and restrained.
\item
  Changes to the Chinese body text should be reflected in the corresponding English translation. English should remain faithful to the Chinese source: remove parentheses that merely repeat a term's English full name, but retain meaningful abbreviations, conditions, and explanations. After changing Markdown in either language, regenerate the corresponding LaTeX and verify compilation of the book and the affected individual sections.
\item
  When reconstructing image content, first identify its type: text, formulas, and tables should be transcribed into the Markdown/LaTeX body; function plots, architecture diagrams, flowcharts, and handwritten schematics should be retained as image resources or redrawn.
\item
  When adding references, prioritize original papers, official documentation, textbook pages, or authors' project pages.
\item
  Curated public image resources under \texttt{assets/images/} may be submitted. Do not upload textbook screenshots, paper figures, or screenshots of commercial materials whose reusability has not been confirmed.
\item
  Do not submit original Word documents, temporary files, cache files, or local materials used for image reconstruction.
\end{itemize}
